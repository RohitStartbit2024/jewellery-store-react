# 💎 Jewellery Store – E-Commerce Frontend

An **E-Commerce user-side frontend application** built with **React + Vite** and **Tailwind CSS**.  
Currently, the project uses **static `.js` data files** (no backend integration yet).  
The app demonstrates a full user flow from authentication to shopping, blogging, and engagement features.

---

## ✨ Features

### 🔐 Authentication
- User **Login & Registration** pages fully styled and responsive.
- State management handled via **Redux**.

### 🛍️ Shopping Experience
- Browse and **search products**.
- **Filter** products by:
  - Category
  - Price
  - Material
- Add products to **Cart**.
- **Place an order** (frontend simulation).

### ⭐ Reviews
- Users can **write reviews** for products.
- Display existing reviews with ratings.

### 📝 Blog Section
- Blogs related to **Jewellery, Lifestyle, Food, Health, and more**.
- Users can:
  - **Read** blog posts
  - **Create** new posts
  - **Comment** and engage with others

### 🖼️ Gallery
- A visually rich **gallery section** to showcase jewellery designs and collections.

### 📱 Responsiveness
- Fully **responsive** design for **desktop, tablet, and mobile** using Tailwind CSS.

---

## 🛠️ Tech Stack

- **React.js** – UI Library
- **Tailwind CSS** – Styling
- **Redux** – State Management
- **Static Data** – Product & Blog data stored in `.js` files

## 🚀 Getting Started

Follow these steps to run the project locally:

### Prerequisites
- Node.js (v16+ recommended)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/RohitStartbit2024/jewellery-store-react.git

# Navigate to project directory
cd jewellery-store

# Install dependencies
npm install

# run
npm run dev

```
Your app will be running at: http://localhost:3000
